The Offline Payment Rails

1. UPI 123Pay IVR Rail

Universal / All SIMs

Uses standard voice call signalling + DTMF (Dual-Tone Multi-Frequency) tones. Supported on all networks including Jio.

  • How OFFLYNE wraps it: Generates DTMF pause string tel:08045163666,,1,<phone>,,<amt>,,1.
  • Muting: OFFLYNE silences phone call audio stream so user doesn't hear screeching tones.
  • Supervision: CallOverlayService provides an Android overlay so the user doesn't feel lost in the dialer.

2. *99# USSD Rail

GSM Only (No Jio)

Uses 2G/3G GSM signalling channel. Fast menu walkthrough for non-Jio telcos (Airtel, Vi, BSNL).

  • How OFFLYNE wraps it: Dials *99*1*3# for Scan QR to directly reach the VPA transfer menu.
  • Limitation: Jio is a pure VoLTE network without 2G GSM fallback, meaning USSD strictly fails on Jio.

3. The Cardinal Verification Invariant

Guaranteed Zero False-Positives
"A payment is only ever promoted to SUCCESS by an incoming bank SMS parsed locally on-device. If no SMS arrives before the 10-minute deadline, the pending attempt is deleted and never reported as success."
